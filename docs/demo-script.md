# 演示短视频分镜（60–90 秒）

> 目标：用一段无旁白也能看懂的短视频，展示「读取状态 → 提出行动 → 用户授权 → 执行 → 核验」和三种失败态。  
> 视频只是补充证据，**不能代替可运行作品**；评审请以仓库与本地运行为准。  
> 已录制版本：`docs/demo/intent-cabin-demo.mp4`（约 80 秒，Playwright 无头录制，带中文字幕）。如需真人录屏 + 旁白，按下表重录即可。

**录制准备：** `python3 -m http.server 8877` → 浏览器打开 `http://127.0.0.1:8877/` → 先点「重置 Demo」→ 窗口 1280×800 → 关闭通知。
