# 演示短视频分镜（约 100 秒）

> 目标：用一段无旁白也能看懂的短视频，展示「读取状态 → 提出行动 → 用户授权 → 执行 → 核验」和三种失败态。  
> 视频只是补充证据，**不能代替可运行作品**；评审请以仓库与本地运行为准。  
> 已录制版本：`docs/demo/intent-cabin-demo.mp4`（约 98 秒，1280×800，无声，带中文字幕）。网页部分为 Playwright 无头录制；0:05–0:23 的 Rinx 段为 Rinx `f18869e` 在 Linux 上的实测截图（`docs/screenshots/rinx-00–04`）加字幕；由 `tools/remake-demo-video.py` 拼接。如需真人录屏 + 旁白，按下表重录即可。

**录制准备：** `python3 -m http.server 8877` → 浏览器打开 `http://127.0.0.1:8877/` → 先点「重置 Demo」→ 窗口 1280×800 → 关闭通知。
